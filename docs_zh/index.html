OpenSpec 中文文档

一个轻量级的规格驱动框架

OpenSpec 帮助你和你的 AI 编程助手在编写任何代码之前就就构建内容达成共识。你描述变更，AI 草拟一份简短的规格说明和任务清单，你们一起查看同一份计划，然后才开始工作。再也不用在半途才发现 AI 构建了错误的东西。

最值得养成的第一个习惯：当你不确定要构建什么时，先用 /opsx:explore 开始。它是一个零成本的思考伙伴，会阅读你的代码、权衡选项，并在任何工件或代码存在之前，将模糊的想法磨砺成具体的计划。探索优先指南说明了为什么这样做。

核心特性

  • 规格即真相 — 规格说明描述系统当前的行为，作为唯一的共同认知来源
  • 变更即单元 — 每次变更都是一个独立的文件夹，包含提案、设计、任务清单和规格增量
  • 增量规格 — 只描述变化的部分（ADDED/MODIFIED/REMOVED），而非重写整个规格
  • 工件有序 — 提案 → 规格 → 设计 → 任务，按自然顺序推进，且随时可回溯修改
  • 归档闭环 — 完成后归档变更，增量规格合并入主规格，形成完整的历史记录

三十秒速览

1. Install        npm install -g @fission-ai/openspec@latest
2. Initialize     cd your-project && openspec init
3. Explore        (in your AI chat)  /opsx:explore           ← optional, but a great habit
4. Propose        (in your AI chat)  /opsx:propose add-dark-mode
5. Build          (in your AI chat)  /opsx:apply
6. Archive        (in your AI chat)  /opsx:archive

第 1、2 步在终端中执行，其余步骤在 AI 助手的聊天中完成。这个分工是最值得记住的一点，命令工作原理详细解释了原因。第 3 步是可选的，但在不确定时以 /opsx:explore 开始是最值得养成的习惯。
