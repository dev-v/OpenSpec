安装指南

npm、pnpm、yarn、bun、Nix，以及如何验证安装成功

前置条件

  • Node.js 20.19.0 或更高版本 — 检查你的版本：node --version

包管理器

npm

npm install -g @fission-ai/openspec@latest

pnpm

pnpm add -g @fission-ai/openspec@latest

yarn

yarn global add @fission-ai/openspec@latest

bun

Bun 可以全局安装 OpenSpec，但 OpenSpec 目前运行在 Node.js 上。你仍需确保 Node.js 20.19.0 或更高版本在 PATH 中可用。

bun add -g @fission-ai/openspec@latest

Nix

直接运行 OpenSpec 而无需安装：

nix run github:Fission-AI/OpenSpec -- init

或安装到你的 profile：

nix profile install github:Fission-AI/OpenSpec

或添加到你的开发环境中的 flake.nix：

{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    openspec.url = "github:Fission-AI/OpenSpec";
  };

  outputs = { nixpkgs, openspec, ... }: {
    devShells.x86_64-linux.default = nixpkgs.legacyPackages.x86_64-linux.mkShell {
      buildInputs = [ openspec.packages.x86_64-linux.default ];
    };
  };
}

验证安装

openspec --version

更新

升级包，然后刷新每个项目的生成文件：

npm install -g @fission-ai/openspec@latest   # or pnpm/yarn/bun equivalent
openspec update                              # run inside each project

openspec update 会重新生成你已配置工具的技能和命令文件，让你的斜杠命令与已安装版本保持同步。

卸载

没有 openspec uninstall 命令，因为 OpenSpec 只是一个全局包加上你项目中的某些文件。移除它只需几步手动操作，且这里不会触及你的源代码。

1. 移除全局包：

npm uninstall -g @fission-ai/openspec   # or: pnpm rm -g / yarn global remove / bun rm -g

2. 从项目中移除 OpenSpec（可选）。如果你不再需要其规格和变更，删除 openspec/ 目录：

rm -rf openspec/

操作前请三思：openspec/specs/ 和 openspec/changes/archive/ 是你系统行为及其变更原因的记录。如果你可能需要这些历史，请保留文件夹（或将其保留在 git 中），即使卸载后。

3. 移除生成的 AI 工具文件（可选）。OpenSpec 会将技能和命令文件写入各工具的目录，如 .claude/skills/openspec-*/、.cursor/commands/opsx-* 等。为你配置的工具删除 openspec-* 技能和 opsx-* 命令。每个工具的确切路径请参见 支持的工具。

如果你在 CLAUDE.md 或 AGENTS.md 等文件中还有 OpenSpec 标记块，请手动移除这些块；这些文件中你自己的内容仍然属于你。

后续步骤

安装后，在你的项目中初始化 OpenSpec：

cd your-project
openspec init

完整走查请参见 快速开始。
