支持的工具

OpenSpec 与 25+ AI 编码助手的兼容列表

OpenSpec 与许多 AI 编码助手兼容。当你运行 openspec init 时，OpenSpec 会使用你选择的活跃配置/工作流选择和交付模式来配置选定的工具。

工作原理

对于每个选定的工具，OpenSpec 可以安装：

  1. Skills（技能）（如果交付包含技能）：.../skills/openspec-*/SKILL.md
  2. Commands（命令）（如果交付包含命令）：特定工具的 opsx-* 命令文件

默认情况下，OpenSpec 使用 core 配置，包括：

  • propose
  • explore
  • apply
  • sync
  • archive

你可以通过 openspec config profile 启用扩展工作流（new、continue、ff、verify、bulk-archive、onboard），然后运行 openspec update。

非交互式设置

对于 CI/CD 或脚本化设置，使用 --tools（以及可选的 --profile）：

# Configure specific tools
openspec init --tools claude,cursor

# Configure all supported tools
openspec init --tools all

# Skip tool configuration
openspec init --tools none

# Override profile for this init run
openspec init --profile core

可用的工具 ID（--tools）： amazon-q, antigravity, auggie, bob, claude, cline, codex, forgecode, codebuddy, continue, costrict, crush, cursor, factory, gemini, github-copilot, iflow, junie, kilocode, kimi, kiro, lingma, vibe, oh-my-pi, opencode, pi, qoder, qwen, roocode, trae, windsurf

依赖工作流的安装

OpenSpec 根据所选工作流安装工作流产物：

  • Core 配置（默认）： propose, explore, apply, sync, archive
  • 自定义选择： 所有工作流 ID 的任意子集： propose, explore, new, continue, apply, ff, sync, archive, bulk-archive, verify, onboard

换句话说，技能/命令的数量取决于配置和交付方式，不是固定的。

生成的技能名称

当根据配置/工作流选择后，OpenSpec 生成这些技能：

  • openspec-propose
  • openspec-explore
  • openspec-new-change
  • openspec-continue-change
  • openspec-apply-change
  • openspec-update-change
  • openspec-ff-change
  • openspec-sync-specs
  • openspec-archive-change
  • openspec-bulk-archive-change
  • openspec-verify-change
  • openspec-onboard

参见命令了解命令行为，参见CLI了解 init/update 选项。
